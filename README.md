# weather-app
A responsive weather application that provides real-time weather information for any city using WeatherAPI. Users can search by location and view live temperature, weather conditions, humidity, and wind speed through a clean and modern UI.
## 🔗 Live Demo
👉 **https://weather-app-seven-mocha-51.vercel.app/**

## 🚀 Features
- 🌍 Search weather by city name
- ⏱ Real-time weather data
- 🌡 Displays temperature in Celsius
- 💧 Shows humidity level
- 🌬 Displays wind speed
- 🎨 Modern and responsive UI
- ⚡ Fast and lightweight

- ## ⚙️ How It Works
1. User enters a city name.
2. JavaScript sends a request to WeatherAPI.
3. Live weather data is fetched.
4. Temperature, weather condition, humidity, and wind speed are displayed instantly.
